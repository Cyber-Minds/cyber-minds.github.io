Course 12 - IoT Device Hardening

Hardening IoT Devices

Internet of Things (IoT) devices are everyday objects with network connectivity — smart thermostats, cameras, printers, warehouse sensors. Northwind Outfitters recently installed a smart shelf-sensor system called ClimateSense Hub to track warehouse humidity. IoT devices are frequently the weakest point in a network because they're easy to forget about.

Default Credentials

Many IoT devices ship with a factory-set username and password, and attackers routinely scan the internet looking for devices that still use them. Changing default credentials before a device ever touches a real network is one of the simplest, highest-value fixes available.

Update Lifecycle

IoT devices need firmware updates just like a computer needs software updates. A device that has reached end-of-life — meaning the manufacturer no longer ships security updates for it — becomes a growing risk the longer it stays connected, even if it still "works fine."

Network Isolation

Rather than placing IoT devices on the same network as computers that handle sensitive data, many organizations put them on a separate, isolated network segment. If a shelf sensor were compromised, network isolation limits an attacker to that isolated segment instead of giving them a path into Northwind's customer database.

Put together: change the defaults, keep firmware current, retire devices that no longer receive updates, and keep IoT traffic away from your most sensitive systems.
